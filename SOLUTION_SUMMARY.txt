================================================================================
                    HRMS LEAVE/WFH BUG FIX - SOLUTION SUMMARY
================================================================================

PROBLEM: Leave and WFH applications stopped working after commit 51aa730

ROOT CAUSE ANALYSIS:
================================================================================

1. BASE URL ISSUE (Critical)
   
   ❌ Changed from: https://vv-vp-api.azurewebsites.net/api/v1/employee
   ❌ Changed to:   https://vv-vp-api.azurewebsites.net/api/v1
   
   Impact: Broke separation between employee and global endpoints
   - Employee endpoints called relative paths like /leaveRequest
   - Global endpoints called full paths like /api/v1/holidays
   - Changing base URL globally broke one type or the other

2. PAYLOAD FORMAT ISSUE (Critical)
   
   ❌ leaveDate sent as array:
      { leaveDate: ["2026-05-20", "2026-05-22"] }
   
   ✓ API expects object format:
      { leaveDate: { fromDate: "2026-05-20", toDate: "2026-05-22" } }

3. TYPE CONVERSION ISSUE (Medium)
   
   ❌ userId: Number(user.userId)
   ✓ Should be: userId: user.userId (keep original type)

================================================================================
